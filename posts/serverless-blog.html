How this blog is served

GitHub Pages holds the files. Cloudflare Workers serves them under blog.nafisainternational.com.

Architecture

This blog is a static site. The HTML, CSS, JavaScript and task data live in a public GitHub repository, and GitHub Pages publishes that directory as a website. There is no application server and no database.

The public URL runs through a Cloudflare Worker. The Worker proxies the same static output from GitHub Pages and adds edge caching, so readers get the site from Cloudflare's network while the source remains easy to update from GitHub.

Why this setup

  • No origin server to patch or maintain.
  • Content changes are ordinary GitHub commits.
  • Cloudflare handles HTTPS, caching and routing.
  • Costs stay at the free tier for both services.
